# Onchain Contract & Token Analysis 集成指南

> 智能合约安全审计——ERC-20 蜜罐检测、权限分析、费用流向、升级风险。

## 适用场景

仅在分析**山寨币/DeFi 代币**时使用。BTC/ETH 不需要合约审计。

## 在分析流程中的使用

### 调用时机

第五步基本面分析中，遇到以下情况时追加：
- 代币市值 < 1 亿美元（小市值合约风险更高）
- 代币上线 < 3 个月（合约未经时间检验）
- 用户要求分析山寨币/土狗币
- 基本面清单中"审计报告"项为 ✗

### 调用方式

```
/skill onchain-contract 审计 {代币合约地址} 在 {链名}
```

### 检查清单

| 检查项 | 风险等级 | 说明 |
|--------|----------|------|
| 合约所有权 | 高 | 所有者是否有无限 Mint/暂停转账权限 |
| 交易税 | 中 | buy/sell tax 是否异常（> 5% 可疑） |
| 蜜罐检测 | 高 | 是否可买入但不可卖出 |
| 流动性锁定 | 高 | LP 是否锁定、锁定多久 |
| 代理合约 | 中 | 是否可升级、升级权限在谁手里 |
| 费用流向 | 中 | 交易费/税金流向哪个地址 |
| 前 100 持仓集中度 | 中 | 前 10 地址持仓 > 50% 标注风险 |

### 结果标注

- 无风险项 → "合约审计通过，未发现显著安全风险"
- 有风险项 → 逐项以【合约安全风险】标注
- 蜜罐/可暂停转账 → 以【严重安全风险】标注，建议回避
