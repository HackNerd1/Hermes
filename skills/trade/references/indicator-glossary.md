# 技术指标在长线场景下的使用手册

## 核心原则

- 长线交易看周线指标，日线仅用于找入场点
- 指标之间互相印证才有效，不依赖单一指标
- 指标是滞后信号，用于确认趋势而非预测转折

## 均线系统（EMA）

| 周期 | 作用 | 长线意义 |
|------|------|----------|
| EMA 21 | 短期趋势 | 日线 EMA21 方向=短期动量 |
| EMA 55 | 中期趋势 | 日线 EMA55 支撑/阻力强度 |
| EMA 200 | 长期趋势 | 周线 EMA200 = 牛熊分界线 |

- EMA21 > EMA55 > EMA200 三线多头排列 → 强多头
- 价格在 EMA200 上方 = 长期牛市，下方 = 长期熊市

## RSI（相对强弱指数）

- 长线看周线 RSI，日线 RSI 噪音大
- 周线 RSI > 70：强势但不一定超买（牛市中 RSI 可长期 >70）
- 周线 RSI < 30：弱势但不一定超卖（熊市中 RSI 可长期 <30）
- **关键信号：周线 RSI 背离**（价格新高 RSI 不新高 = 顶背离）

## MACD

- 长线看周线 MACD，忽略日线 MACD 的短期交叉
- 周线 MACD 金叉/死叉 = 中期趋势转折信号
- 死叉**不单独减仓**；退出由 Donchian 中轨跟踪止损负责
- MACD 柱状体连续 3 周收敛 = 动能减弱

## ADX（平均趋向指数）

- 只看周线 ADX，忽略日线 ADX
- ADX 是趋势强度的滞后确认，**不是入场闸门**；只决定仓位档
- 仓位系数：ADX < 20 → 0.5；20-25 → 0.75；25-40 → 1.0；> 40 → 1.0（禁止加仓，不强制减仓）
- 系数乘在最终仓位上；ADX 只缩放仓位，不单独决定是否开仓
- ADX 单独使用容易把趋势启动期过滤掉；与 DI 同向或价格创新高/新低配合时才加仓

## Donchian 通道（10 周）

- 上沿 = 前 10 周最高收盘；下沿 = 前 10 周最低收盘（均指已收盘的 10 根周线，不含当前周）
- 中轨 = (上沿 + 下沿) / 2
- 周线收盘突破上沿/下沿 → 突破入场信号（stop-limit 跟进）
- 初始止损 = 入场价 ∓ 2×N（N = 日线 ATR(20)）
- 跟踪止损 = 多头 `max(初始止损, 中轨)` / 空头 `min(初始止损, 中轨)`，只朝有利方向移动；中轨越过现价时不采用
- 通道下沿/上沿不作为跟踪止损，但收盘跌破下沿（多头）/ 升破上沿（空头）仍触发破位出场
- 持仓期间的新突破只作加仓信号，不改变已有持仓的止损锚点；加仓时止损上移到最新加仓价 ∓ 3N（见 [position-mgmt.md](./position-mgmt.md)）
- 与 EMA21/55 的关系：EMA 定方向，通道定入场/出场；不要把两者混成一个门槛

## 布林带

- 长线看周线布林带
- 带宽收窄至历史低位 = 大波动临近（变盘信号）
- 价格沿上轨运行 = 强势（不一定是卖出信号）
- 价格沿下轨运行 = 弱势（不一定是买入信号）

## 成交量

长线最核心的量价关系：

- 上涨放量回调缩量 = 需求主导，趋势健康
- 上涨缩量下跌放量 = 供应主导，趋势有问题
- 周线级别缩量横盘 = 吸筹/派发区域
- 成交量只用于报告叙述与评分，不进入仓位公式，不触发减仓（见 long-term-rules.md 第二节）

## ATR（平均真实波幅）

- N = 日线 ATR(20)（Wilder）是初始止损与 sizing 的输入：初始止损 = 入场价 ∓ 2×N（见 [position-mgmt.md](./position-mgmt.md)）；跟踪出场用 Donchian 中轨。
- 止损距离 > 8% 只做风险提示，不压缩止损；仓位由波动率目标决定。
- ATR 急剧放大 = 波动率飙升，按 `target_vol / realized_vol_90d` 减小仓位
