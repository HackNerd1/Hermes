# 仓位管理规则

## 仓位分级

| 级别 | 仓位比例 | 触发条件 |
|------|----------|----------|
| 空仓 | 0% | 周线 ADX<20 或趋势不明 |
| 轻仓 | 10-20% | 周线趋势初现，ADX 20-25 |
| 标准仓 | 30-50% | 周线趋势明确，ADX 25-40 |
| 重仓 | 60-80% | 周线强趋势 + 日线回调确认，且 ADX≤40（仅 BTC/ETH） |
| 满仓 | 禁止 | 硬顶 80%，禁止 100% |

名义仓位比例 = min(上表该档上沿, 币种硬顶, 风险反推仓位比例)。

- BTC/ETH 硬顶 80%，取 `technical-indicators` `position_sizer.MAX_POSITION_PCT`。因此重仓上沿 80% 可达，不再另设 30% 币种帽。
- 非 BTC/ETH 硬顶 20%（与下方山寨币公式上限一致）。标准仓、重仓的 30% 以上档只适用于 BTC/ETH；山寨即使 ADX 25-40，名义仓位仍不超过 20%。
- ADX>40：不加仓。不把已有仓降到 0，也不升入重仓。
- `market-structure` 不提供仓位比例，不参与这条上限。

## 风险系数（单笔最大亏损 ≤ 总资金 × 风险系数）

| risk_tolerance | 系数 |
|------|------|
| conservative | 1% |
| moderate（默认） | 2% |
| aggressive | 3% |

风险反推仓位比例 = 风险系数 × 入场价 / 止损距离（等价于先算数量 `风险系数 × 总资金 / 止损距离`，再乘入场价、除以总资金折成比例）。

## 止损规则

- 止损价 = `market-structure` 的实时结构失效位再让出 **0.5×周线 ATR** 的缓冲：多头 = 结构失效位 − 0.5×周线 ATR，空头 = 结构失效位 + 0.5×周线 ATR。周线 ATR 由 `technical-analyst` / `technical-indicators` 计算；「结构位 + 缓冲」的整体才是止损距离，缓冲本身不是止损距离。
- 止损距离 = |入场价 − 止损价|。具体价格不在本文件保存，由执行层按实时数据生成。
- 止损距离 > 入场价 × 5% → 标注高风险；仓位按风险反推自动收紧，不因此禁止开仓。
- 盈利 > 10% → 止损移到成本价（保本止损）。

## 止盈规则

- 趋势减仓信号必须由 `technical-indicators` 的实时周线 ADX/MACD/EMA 结果产生；本文件只定义减仓比例。
- ADX 从 >30 回落至 <25 → 减仓 50%
- 周线 MACD 死叉 → 减仓 70%
- 周线 EMA21 下穿 EMA55 → 清仓

## 仓位计算公式

```
# 单笔最大亏损 = 总资金 × 风险系数（见风险系数表）
# 止损距离 = |入场价 - (结构失效位 ± 0.5×周线 ATR)|（见止损规则）
# 风险反推仓位比例 = 风险系数 × 入场价 / 止损距离
# 名义仓位比例 = min(仓位分级上沿, 币种硬顶, 风险反推仓位比例)

# 山寨币仓位上限
if BTC.D > 60:
    altcoin_max = 10%
elif BTC.D < 40:
    altcoin_max = 20%
else:
    altcoin_max = max(10%, (60 - BTC.D) / 2 * 10%)
```
