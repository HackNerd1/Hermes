# 仓位管理规则

> 本文件是仓位、止损、跟踪出场与目标仓位的 Source of Truth。
> 入场方向与趋势门槛见 [long-term-rules.md](./long-term-rules.md)；执行流程见 [trade-execution.md](./trade-execution.md)。
> 2026-11-01 修订：跟踪出场由「前 10 周最低收盘」改为 **Donchian 中轨**；初始止损与 sizing 统一用 **2×日线 ATR(20)**；删除量能系数与固定止盈（TP1）。依据见 `docs/colosseo-llm-replay/skill-optimization-research.md`。

## 仓位分级

| 级别 | 名义仓位上限 | 触发条件 |
|------|----------|----------|
| 空仓 | 0% | 趋势系数 = 0（见 `long-term-rules.md` 1.1） |
| 轻仓 | 20% | 非 BTC/ETH（硬顶即 20%） |
| 标准仓 | 50% | BTC/ETH |
| 重仓 | 80% | BTC/ETH 且突破/回调确认 |
| 满仓 | 禁止 | 硬顶 80% |

- **档位是上限，不是目标仓位**：实际名义比例 = `min(档位上限, 币种硬顶, vol_weight, risk_cap_weight) × 趋势系数 × ADX 系数`。风险上限或波动率目标经常是约束项，报告必须同时给出「档位上限」与「实际名义比例」。
- 非 BTC/ETH 硬顶 20%；标准仓、重仓的 30% 以上档只适用于 BTC/ETH。
- `market-structure` 不提供仓位比例，不参与这条上限。

### 两个系数（只缩放仓位，不决定是否开仓）

| 系数 | 取值 | 说明 |
|---|---|---|
| 趋势系数 | 1.0 / 0.5 / 0.3 / 0 | 见 `long-term-rules.md` 1.1；EMA 方向只缩放仓位，不再做硬闸门 |
| ADX 系数 | <20 → 0.5；20–25 → 0.75；25–40 → 1.0；>40 → 1.0（禁止加仓） | 周线 ADX；只缩放仓位 |

- 两个系数都乘在最终仓位上；系数相乘只降不升，名义比例最多等于 `min(档位上限, 硬顶, vol_weight, risk_cap_weight)`。
- ADX>40：维持当前仓位与档位，**禁止加仓，不强制减仓**。

## 方向规则（长线默认 long-only）

- `mode=long`（周线趋势）默认只做多/空仓；不因为「跌得多」而做空。`mode=short` 的 4H 空头按短线规则，不受本节周线门槛约束。
- **空头是实验分支，默认关闭**：BTC 2018–2026 回放里空头 6 腿合计 +82.64 USDT，8.75 年基本为零贡献却带来复杂度。只有用户明确要求做空时才启用，且需同时满足：
  1. 周线 EMA21 < EMA55 且双线下行；
  2. 价格 < 200 日均线；
  3. 周线收盘跌破前 10 周最低收盘（突破做空，不做回调做空）。
- 启用空头时，风险预算 = 同档多头的 **50%**：target_vol 减半，单笔风险上限取对应 risk_tolerance 的一半。
- 空头初始止损 = 入场价 + 2N（N = 日线 ATR(20)）；跟踪止损 = Donchian 中轨（镜像）。
- 200 日均线上方禁止做空；逆势反弹不补空。

## 组合层上限（多币种）

- 同时持仓 ≤ **5 个币种**（`coin_screener.MAX_POSITIONS`）。
- BTC/ETH 合计名义 ≤ 80%；非 BTC/ETH 合计名义 ≤ 40%。
- 同类别/高相关（60 日相关系数 > 0.7）币种合计 ≤ **2 个**，合计名义 ≤ 40%。
- 组合总名义 ≤ 100%（现货，不加杠杆）；所有单币种仍受 80%/20% 硬顶与 `vol_weight` 约束。
- 选币范围：BTC/ETH + 市值/成交额前 20 的流动币；排除稳定币、日成交额不足、上线 < 90 天、流动性评分不足的币。
- 相关性检查：优先用 60 日收益率相关系数；没有数据时用 `coin-picker` 的 category 作为代理。
- 组合层约束不替代单币种 sizing：先按单币种算，再按组合上限缩放。

## 波动率目标仓位（主 sizing）

| risk_tolerance | target_vol（年化） | 单笔风险上限 |
|------|------|------|
| conservative | 10% | 1% |
| moderate（默认） | 20% | 2% |
| aggressive | 30% | 3% |

- `target_vol` 是收益/回撤的主旋钮：BTC 2018–2026 影子回测里 20% → 25% → 35% 对应 CAGR 19.9% → 25.0% → 35.6%、MDD -13.1% → -16.1% → -22.0%，Sharpe 基本持平（1.18–1.21）。选哪一档是风险偏好问题，不是规则对错。
- 现货不能加杠杆，名义仓位天然 ≤100%；`vol_weight` 超过硬顶时按硬顶；算出的仓位低于最小下单量时按 [trade-execution.md](./trade-execution.md) 的冲突处理，不放大风险。

```
N = 日线 ATR(20)（Wilder 平滑）
target_vol = 10% / 20% / 30%（conservative / moderate / aggressive）
realized_vol_90d = 90 日已实现波动率（年化）
vol_weight = target_vol / realized_vol_90d
risk_cap_weight = 风险系数 × 入场价 / (2 × N)      # 与初始止损同源
名义仓位比例 = min(档位上限, 币种硬顶, vol_weight, risk_cap_weight) × 趋势系数 × ADX 系数
```

- `vol_weight` 是主 sizing；`risk_cap_weight` 是上限。
- **止损距离一律取 2×N**，不再用「结构位到通道下沿」的距离。结构失效位只作参考——否则价格越强、止损越宽、仓位越小，方向做反。
- 仓位惯性：当前仓位与目标仓位的偏差 < 目标 × **20%** 时不再调整（原 10%，提高到 20% 以降低换手成本）。
- 单笔最大亏损仍 ≤ 总资金 × 风险系数（见上表）。

## 止损规则

- N = **日线 ATR(20)**（Wilder 平滑），不是周线 ATR。
- **初始止损 = 入场价 ∓ 2N**（多头减、空头加）。
- **一个持仓只有一个止损价，锚点在首次建仓时确定**。持仓期间出现新的 10 周通道突破但未加仓时，**不改变锚点**；加仓时按「加仓规则」上移。
- 止损距离 = |入场价 − 初始止损价| = 2N。
- 止损距离 > 入场价 × **8%** → 标注高风险；**不因此禁止开仓，也不压缩止损**。
- **跟踪止损（默认退出）= Donchian 中轨**：
  - 多头：`candidate = max(当前止损, (前 10 周最高收盘 + 前 10 周最低收盘) / 2)`；
  - 空头：`candidate = min(当前止损, (前 10 周最高收盘 + 前 10 周最低收盘) / 2)`；
  - 若多头 `candidate ≥ 当前价`（空头 `candidate ≤ 当前价`）→ **不采用**，维持原止损，下周再试（避免回调入场时把止损放到现价之上）；
  - 只朝有利方向移动；每周收盘后更新。若平台无法挂跟踪单，按周线收盘确认后平仓。
  - 「前 10 周最高/最低收盘」指决策时点之前**已收盘**的 10 根周线，不含当前正在形成的周线。
- **前 10 周最低/最高收盘不作为跟踪止损**，只在报告中作为「通道下沿/上沿」披露；但收盘跌破下沿仍触发上面的破位出场。
- 可选变体：3×周线 ATR 跟踪位（`最高收盘 − 3×ATR周` / `最低收盘 + 3×ATR周`），仅用于 A/B，不作为默认。
- 取消「TP1 后移损到成本、TP2 后移到 TP1」。

## 止盈/出场规则

- **默认跟踪出场**：按上节 Donchian 中轨，收盘触发 → 清仓。
- **破位出场（独立于中轨）**：周线收盘跌破前 10 周最低收盘（多头）/ 升破前 10 周最高收盘（空头）→ 清仓。
  - 用途：回调入场时价格常在中轨下方，中轨不能作为止损；此时靠这条与 2N 初始止损兜底。
  - 与跟踪止损的区别：破位出场按「前 10 周最低收盘」判断，不看中轨；触发后无条件清仓。
- **不设固定止盈**（删除原 TP1）。趋势系统的收益来自少数大赢家，部分止盈会系统性降低期望；回放里 TP1 在强趋势中从未触发，小仓位下 1/3 还常低于最小下单量。
- 若用户明确要求落袋：仅在浮盈 **≥ 4R** 时平 **1/4**，每个持仓一次，**默认关闭**；不足最小下单量则不执行，也不改写为满仓止盈。
- 趋势减仓：
  - 周线 MACD 死叉不单独触发减仓；退出由中轨跟踪负责。
  - 周线 EMA21 下穿 EMA55：趋势系数降到 0.3 时降到轻仓；降为 0 时清仓（见 `long-term-rules.md` 1.1）。
  - 周线 ADX 从 >30 回落至 <25 → 不单独减仓；只作为仓位系数。
- 不设 TP2/TP3 固定档；剩余仓位全部交给跟踪止损。

## 建仓节奏

- **首次建仓**：回调入场与突破入场都**一次建满计划 unit**，不按 1/3 阶梯分批。
- 理由：2N 止损已经定义了单笔风险；再按 1/3 建仓等于把风险预算只用掉三分之一，三个样本窗口的 A/B 显示这是跑输旧规则的主因（见 `docs/colosseo-llm-replay/skill-optimization-research.md` 第 8 节）。

## 加仓规则（Turtle 式 unit）

- 加仓 = 新增一个 unit，不是在旧仓位上追加。
- 间距：沿趋势方向每 **0.5×N**（N = 日线 ATR(20)）加一次，最多加 **2 次**（合计最多 3 个 unit）；非 BTC/ETH 不加仓。
- **加仓时止损上移到最新加仓价 ∓ 3N**（只朝有利方向移动），旧 unit 因此自动锁定部分利润。
- 为什么是 3N 而不是 2N：Turtle 的 2N 适合日线流动性市场；BTC 周线的正常回踩经常超过 2N。三个样本窗口的 A/B 里，加仓后一周内被整仓打掉出现了 3 次（2023-11、2023-12、2025-01），改 3N 是为了给加仓后的仓位留出周线级噪声空间。初始止损仍为 2N。
- 加仓前检查：加仓后所有 unit 在当前止损下的合计亏损 ≤ 单笔风险预算（风险系数 × 总资金）；超出则减少加仓数量，不足最小下单量则不加仓。
- 不加仓时，止损只按 Donchian 中轨规则上移，不因新突破抬升。

## 仓位计算公式（汇总）

```
# 波动率目标（主）
target_vol = 10% / 20% / 30%
vol_weight = target_vol / realized_vol_90d

# 风险上限（与 2N 止损同源）
risk_cap_weight = 风险系数 × 入场价 / (2 × N)

# 名义仓位
名义仓位比例 = min(档位上限, 币种硬顶, vol_weight, risk_cap_weight) × 趋势系数 × ADX 系数

# 山寨币仓位上限
if BTC.D > 60:
    altcoin_max = 10%
elif BTC.D < 40:
    altcoin_max = 20%
else:
    altcoin_max = max(10%, (60 - BTC.D) / 2 * 10%)
```
