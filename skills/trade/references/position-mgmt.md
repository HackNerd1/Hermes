# 仓位管理规则

## 仓位分级

| 级别 | 仓位比例 | 触发条件 |
|------|----------|----------|
| 空仓 | 0% | 周线 ADX<20 或趋势不明 |
| 轻仓 | 10-20% | 周线趋势初现，ADX 20-25 |
| 标准仓 | 30-50% | 周线趋势明确，ADX 25-40 |
| 重仓 | 60-80% | 周线强趋势 + 日线回调确认（仅 BTC/ETH） |
| 满仓 | 禁止 | 永不满仓 |

## 止损规则

- 止损位必须由 `market-structure` 的实时结构失效位生成，并使用 `technical-indicator-pro` 的 ATR 计算缓冲；本文件不保存或推导具体市场价格。
- 止损距离 > 总资金 2% → 减小仓位直到满足 2% 规则
- 盈利 > 10% → 止损移到成本价（保本止损）

## 止盈规则

- 趋势减仓信号必须由 `technical-indicator-pro` 的实时周线 ADX/MACD/EMA 结果产生；本文件只定义减仓比例。
- ADX 从 >30 回落至 <25 → 减仓 50%
- 周线 MACD 死叉 → 减仓 70%
- 周线 EMA21 下穿 EMA55 → 清仓

## 仓位计算公式

```
# 单笔最大亏损 = 总资金 × 2%
# 止损距离 = |OKX 实际/可执行入场价 - 结构失效位与 ATR 缓冲后的止损价|
# 最大仓位 = 单笔最大亏损 / 止损距离

# 山寨币仓位上限
if BTC.D > 60:
    altcoin_max = 10%
elif BTC.D < 40:
    altcoin_max = 20%
else:
    altcoin_max = max(10%, (60 - BTC.D) / 2 * 10%)
```
