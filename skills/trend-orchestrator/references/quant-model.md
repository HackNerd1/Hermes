# 自定义基本面量化模型

> 将长线铁律中的定性判断量化为可计算的分值体系，减少主观偏差。

## 评分模型架构

```
总分 = 技术面得分 × 0.35 + 量价得分 × 0.20 + 基本面得分 × 0.20 + 消息面得分 × 0.15 + 铁律对照 × 0.10
```

## 各维度评分标准

### 技术面（满分 100，权重 0.35）

| 指标 | 条件 | 分值 |
|------|------|------|
| 周线 EMA 排列 | EMA21 > EMA55 > EMA200 | +30 |
| | EMA21 > EMA55 (EMA200 下方) | +15 |
| | EMA 缠绕 | 0 |
| | EMA21 < EMA55 (空头排列) | -20 |
| 周线 ADX | 25-40 (趋势明确) | +25 |
| | 20-25 (趋势形成中) | +10 |
| | < 20 (无趋势) | -10 |
| | > 40 (极端趋势) | 0 (不加分，警惕反转) |
| 周线 RSI | 40-70 (健康区域) | +20 |
| | 30-40 或 70-80 | +5 |
| | < 30 (超卖) | -5 (可能反弹) |
| | > 80 (极端超买) | -10 |
| 周线 MACD | 金叉 + 柱状体向上 | +25 |
| | 金叉但柱状体走平 | +10 |
| | 死叉 | -20 |

### 量价关系（满分 100，权重 0.20）

| 指标 | 条件 | 分值 |
|------|------|------|
| 周线量价配合 | 上涨放量、回调缩量 | +40 |
| | 量价无明显背离 | +15 |
| | 周线级别量价背离 | -40 ([风险警示]) |
| 关键位置量能 | 突破放量 (>1.5x 均量) | +30 |
| | 突破缩量 | -20 ([假突破风险]) |
| 成交量趋势 | 周线成交量温和放大 | +30 |
| | 周线成交量萎缩 | -10 |

### 基本面（满分 100，权重 0.20）

| 维度 | 条件 | 分值 |
|------|------|------|
| 团队 | 公开团队 + 成功过往项目 | +25 |
| | 公开团队无过往项目 | +10 |
| | 匿名团队 | -20 |
| 代币经济 | 通胀 < 5%/年 + 有销毁机制 | +25 |
| | 通胀 5-20%/年 | +5 |
| | 通胀 > 20%/年 | -15 |
| 解锁 | 6 个月内无大额解锁 | +25 |
| | 6 个月内解锁 > 5% 流通量 | -25 ([解锁风险]) |
| 链上活跃 | 日活地址/交易数月级别增长 | +25 |
| | 日活稳定 | +10 |
| | 日活月级别下降 > 20% | -15 |

### 消息面（满分 100，权重 0.15）

| 条件 | 分值 |
|------|------|
| 有重大利好（ETF 获批/主网上线/重大合作） | +30 |
| 消息面平静 | +15 |
| 有重大利空（监管打击/黑客/团队动荡） | -30 |
| 宏观环境有利（降息周期/宽松） | +20 |
| 宏观环境不利（加息周期/紧缩） | -15 |
| 多条来源一致 | +20 (加分) |
| 消息矛盾/不确定 | 0 |

### 铁律对照（满分 100，权重 0.10）

| 条件 | 分值 |
|------|------|
| 无铁律触发 | +100 |
| 每条 [风险警示] | -25 |
| 触发 3 条以上 | 总分强制 ≤ 40 |

## 最终评分与操作建议

| 总分 | 等级 | 操作建议 |
|------|------|----------|
| ≥ 75 | A — 强趋势 | 关注建仓/加仓机会 |
| 60-74 | B — 趋势良好 | 可持有，等回调确认加仓 |
| 45-59 | C — 趋势不明 | 观望，不新建仓位 |
| 30-44 | D — 有风险 | 减仓，仅保留底仓 |
| < 30 | F — 高风险 | 回避/清仓 |

## 使用说明

1. 评分在第七步铁律对照后执行
2. 评分结果写入报告的"综合建议"部分
3. 评分仅辅助决策，不可替代铁律对照
4. 铁律触发 ≥ 3 条时，总分数强制 ≤ 40，无论其他维度得分如何
