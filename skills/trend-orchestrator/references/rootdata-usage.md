# RootData 基本面分析集成指南

> 项目数据库：团队背景、融资历史、代币分配、解锁计划、社交指标。

## 数据覆盖范围

| 维度 | 内容 | 长线分析价值 |
|------|------|-------------|
| 团队背景 | 创始团队履历、过往项目、LinkedIn/GitHub | 评估项目执行能力 |
| 融资历史 | 融资轮次、金额、投资方、估值 | 判断机构认可度和筹码成本 |
| 代币分配 | 团队/投资人/社区/生态比例 | 识别抛压风险 |
| 解锁计划 | 未来 6-12 个月的解锁时间表 | 提前预警供应冲击 |
| 社交指标 | Twitter/Telegram/Discord 活跃度 | 市场情绪和社区健康度 |

## 在分析流程中的使用

### 第五步调用方式

```
/skill rootdata 查询 {项目名/代币名} 的基本面数据
```

### 重点关注指标

1. **解锁风险**：未来 6 个月解锁量 > 当前流通量 5% → 标注【解锁风险】
2. **团队代币占比**：> 30% → 标注【中心化风险】
3. **融资估值泡沫**：最后一轮估值远高于同类项目 → 标注【估值风险】
4. **社交活跃度骤降**：30 天内互动量下降 > 50% → 标注【社区衰退】

### 不同代币类型的分析深度

**BTC/ETH（从简）：**
- 仅关注：大额解锁事件、机构持仓变化、社交情绪极端值

**山寨币（标准）：**
- 全面检查所有维度
- 团队背景逐项核实
- 解锁时间表完整列示

**DeFi 代币（深度）：**
- 标准检查 + TVL 趋势 + 协议收入
- 追加 Heurist Mesh 获取链上数据
