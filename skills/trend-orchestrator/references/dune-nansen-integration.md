# Dune / Nansen 链上数据集成指南

> 引入专业链上数据分析平台，补充项目级基本面数据中缺失的实时链上指标。

## 数据源定位

| 平台 | 擅长 | 数据类型 | 成本 |
|------|------|----------|------|
| **Dune Analytics** | 自定义 SQL 查询，社区看板 | 交易量/用户数/协议收入/TVL | 免费 |
| **Nansen** | 巨鲸追踪，Smart Money 标签 | 地址标签/资金流向/持仓变化 | 付费 |

## 集成方式

### Dune（通过 WebFetch 间接集成）

```
使用 WebFetch 获取 Dune 看板数据：
https://dune.com/queries/{query_id}
```

长线分析关注的 Dune 看板维度：
- 交易所 BTC/ETH 余额变化（30 日趋势）
- 稳定币发行量/销毁量
- DeFi 协议 TVL 排名变化
- NFT 市场交易量趋势

### Nansen（通过手动导出集成）

Nansen 数据作为分析输入参考：
- Smart Money 地址最近 30 天持仓变化
- 交易所净流入/流出（CEX Netflow）
- 稳定币持有者行为变化

## 在分析流程中的使用

### 第二步补充（数据获取层）

在 okx/agent-skills 拉取 K 线数据后，可选追加链上数据：

```
用 WebFetch 查询 Dune 看板 {dashboard_id}：
- BTC 交易所余额 30 天变化
- 稳定币 (USDT/USDC) 交易所余额变化
```

### 第五步补充（基本面层）

山寨币/DeFi 代币分析时：
```
用 WebFetch 查询该协议的 Dune 看板：
- 日活用户 30 天趋势
- TVL 排名变化
- 协议费用收入趋势
```

## 关键指标与长线信号

| 指标 | 看多信号 | 看空信号 |
|------|----------|----------|
| 交易所 BTC 余额 | 持续下降（囤币） | 持续上升（抛压） |
| 稳定币交易所余额 | 持续上升（抄底资金） | 持续下降（资金流出） |
| 巨鲸持仓 | Smart Money 增持 | Smart Money 减持 |
| 协议 TVL | 稳步增长 | 持续下降 |
| 日活用户 | 月级别增长 | 月级别下降 > 20% |

## 限制

- Dune 数据有延迟（通常 5-30 分钟）
- Nansen 付费 API 需额外配置
- 链上数据可能被女巫攻击/清洗交易污染
- 仅作为辅助参考，不作为独立决策依据
